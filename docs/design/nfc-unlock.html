BOUNDARY / IMPLEMENTATION

安全与交互边界

NFC 是“身份验证的本地补充”，不是新的网络传输协议。这样能复用现有 BLE / 局域网与签名解锁链路。

01
电脑不读取 NFCNFC 由手机读取，电脑端只展示钥匙指纹、最近使用时间与验证结果。
02
卡片不是密码容器卡片只保存随机身份令牌；Windows 密码与私钥始终留在受保护的本机存储。
03
先验证，再解锁扫描状态和网络请求状态分开表达，避免把“读卡成功”误认为“电脑已解锁”。
04
状态不只靠颜色等待、成功、拒绝都同时使用图标、标题和辅助文案，照顾色觉差异。
